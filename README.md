## Mes 2 domaines préférés

### Domaine 1 : Web

- Expérience : J'ai fait quelques projets en Web 1.
- Logiciels et outils : Je sais comment utiliser le HTML et la plupart du CSS. J'aimerais aussi apprendre le Python ou le JavaScript.
- Pourquoi il m'intéresse : Ça m'a plu dès le moment où on a commencé à le faire dans Web 1. Ce n'était pas quelque chose qui m'intéressait trop avant ce cours, mais j'ai fini par accrocher.
- Travailler dans ce domaine : Je ne me vois pas vraiment travailler là-dedans, surtout parce que c'est quelque chose que je considère plus comme un passe-temps.

### Domaine 2 : Jeux vidéo

- Expérience : Je n'ai joué qu'à des jeux vidéo, mais je n'ai pas vraiment expérimenté la création de quoi que ce soit. La seule chose réelle que j'ai faite, c'est combiner des animations déjà créées pour en faire d'autres dans un jeu.
- Logiciels et outils : Pour être honnête, je ne connais vraiment aucun, mais j'aimerais apprendre à créer les animations du joueur.
- Pourquoi il m'intéresse : J'ai joué à des jeux vidéo pendant une bonne partie de ma vie et je me suis toujours demandé comment les gens arrivent à créer ces chefs-d'œuvre.
- Travailler dans ce domaine : C'est quelque chose dans lequel je pourrais me voir travailler parce que créer des jeux semble être un domaine dans lequel ça ne me dérangerait pas de m'impliquer.
